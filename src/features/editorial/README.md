# Editorial Feature Rules

## Core Principle

Editorial handles curated experiences and content organization layers.

It remains experience-focused and frontend-oriented.

---

# Allowed Responsibilities

Examples:

- playlists
- curated collections
- editorial discovery
- featured content
- recommendation presentation

---

# Forbidden Responsibilities

Avoid:

- streaming analytics ownership
- monetization authority
- backend orchestration
- infrastructure authority
- AI provider ownership

---

# Important Principle

Editorial coordinates curated user experiences.

Heavy recommendation systems and analytics remain isolated in backend and intelligence layers.
