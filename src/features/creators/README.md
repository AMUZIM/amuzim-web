# Creators Feature Rules

## Core Principle

Creators handles creator-facing experiences and participation workflows.

It remains frontend-oriented and feature-isolated.

---

# Allowed Responsibilities

Examples:

- creator profiles
- publishing UI
- creator dashboards
- creator interactions
- creator experience flows

---

# Forbidden Responsibilities

Avoid:

- monetization authority
- royalties ownership
- infrastructure orchestration
- deployment workflows
- advanced analytics ownership

---

# Important Principle

Creators coordinates creator experiences.

Protected monetization and analytics systems remain isolated in backend and streaming infrastructure layers.
