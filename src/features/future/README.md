# Future Feature Rules

## Core Principle

Future contains experimental and forward-looking frontend experiences.

It must remain isolated from protected operational systems.

---

# Allowed Responsibilities

Examples:

- experimental interfaces
- future interaction concepts
- AI-native UX exploration
- innovation prototypes
- future ecosystem experiences

---

# Forbidden Responsibilities

Avoid:

- production infrastructure authority
- monetization ownership
- deployment workflows
- protected operational systems
- backend authority

---

# Important Principle

Future is an experimentation layer.

Experiments must remain isolated, controlled, and scalable.
