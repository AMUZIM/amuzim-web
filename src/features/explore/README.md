# Explore Feature Rules

## Core Principle

Explore handles discovery and ecosystem exploration experiences.

It remains frontend-oriented and experience-focused.

---

# Allowed Responsibilities

Examples:

- discovery feeds
- recommendations presentation
- trending surfaces
- exploration UI
- discovery navigation

---

# Forbidden Responsibilities

Avoid:

- monetization authority
- backend orchestration
- streaming analytics ownership
- infrastructure authority
- AI provider ownership

---

# Important Principle

Explore coordinates discovery experiences.

Heavy recommendation logic and analytics remain isolated in backend and intelligence layers.
