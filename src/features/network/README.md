# Network Feature Rules

## Core Principle

Network handles lightweight social interaction systems only.

Advanced analytics and monetization reporting do not belong here.

---

# Allowed Responsibilities

Examples:

- likes
- comments
- reactions
- follows
- lightweight engagement
- community interactions

---

# Forbidden Responsibilities

Avoid:

- royalties
- advanced analytics
- territory reporting
- monetization reporting
- streaming infrastructure authority

---

# Important Principle

Network remains lightweight and frontend-oriented.

Advanced operational analytics belong to streaming infrastructure layers.
