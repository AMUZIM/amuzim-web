# Shared Components

This folder contains reusable UI and structural components shared across multiple domains.

## Purpose
Components here should be:
- reusable
- domain-agnostic
- layout-oriented
- shared across features

## Do NOT place here
Feature-specific logic belongs inside:

- src/features/explore
- src/features/creators
- src/features/future
- src/features/network
- src/features/editorial
- src/features/shorts

## Examples
Good candidates:
- layout wrappers
- shared sections
- generic containers
- reusable structural blocks
