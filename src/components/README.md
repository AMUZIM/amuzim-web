# Legacy Components Layer

## Status

This layer is transitional legacy structure.

New reusable UI must not be created here.

---

# Migration Direction

Progressive migration targets:

- src/ui
- src/features

---

# Allowed Usage

Temporary maintenance only.

Examples:

- existing compositions
- temporary compatibility
- gradual extraction support

---

# Forbidden Usage

Avoid:

- new reusable systems
- new design-system primitives
- new global abstractions
- uncontrolled component growth

---

# Long-Term Goal

This layer will progressively shrink as the frontend architecture consolidates.
