# Navigation Rules

## Core Principle

Navigation systems coordinate ecosystem movement and route accessibility.

Navigation must remain reusable and business-agnostic.

---

# Allowed Responsibilities

Examples:

- route navigation
- dashboard navigation
- menu systems
- sidebar systems
- public navigation

---

# Forbidden Responsibilities

Avoid:

- business authority
- feature ownership
- backend orchestration
- provider logic

---

# Important Principle

Navigation coordinates frontend access flows only.

Business logic belongs inside features and backend systems.
